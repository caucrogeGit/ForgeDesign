Diagnostic Forge

Lance la commande officielle forge doctor du projet, uniquement sur votre demande, et affiche son résultat sans l’interpréter ; les affectations sensibles reconnues (mot de passe, jeton, clé d’API…) sont masquées, sans garantie d’exhaustivité. Rien n’est enregistré : le résultat disparaît avec cette page.

Le diagnostic Forge est exécuté avec l’environnement Python du projet (.venv/bin/python) dans un processus séparé. Il exécute la configuration du projet et peut donc exécuter son code ou accéder aux services qui y sont configurés, notamment la base de données.
